# CloudSpend: Cloud-Based Personal Finance and Expense Management System

## Project Description
**CloudSpend** is a secure, scalable, 3-tier cloud-native web application designed to help individuals and families track monthly income, categorize daily expenses, and enforce category-wise spending budgets in real time.

Containerized using **Docker** and provisioned automatically on **Amazon Web Services (AWS)** via modular **Terraform** Infrastructure as Code (IaC), the system eliminates manual spreadsheet tracking and safeguards financial records inside isolated private network subnets.

### Key Functionalities
- **Secure Multi-User Authentication:** Private user signup and login with isolated financial records.
- **Income & Expense Logging:** Fast entry and searchable ledger for monthly inflows and categorized expenditures.
- **Category Budget Guardrails:** Customizable monthly spending limits with live color-coded adherence alerts (`Safe`, `Warning`, `Over-Budget`).
- **Real-Time Analytics Dashboard:** Instant calculation of Net Savings, Savings Rate, and interactive Expense Breakdown charts.

### AWS Services Used
- **Networking:** Amazon VPC (Public, Private App, and Isolated DB Subnets) & NAT Gateway
- **Compute & Scaling:** Application Load Balancer (ALB), Auto Scaling Group (ASG), and Amazon EC2 (Docker)
- **Database:** Amazon RDS (PostgreSQL)
- **Security & Monitoring:** AWS IAM, Systems Manager (SSM) Parameter Store, Amazon CloudWatch, SNS, and Terraform
